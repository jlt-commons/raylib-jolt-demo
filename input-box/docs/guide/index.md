# input-box

type into a text box (GetCharPressed)

Category: text

Ported from raylib's `examples/text/text_input_box.c`.

![input-box](../demos/input-box.gif)

## Run it

```sh
cd input-box && bb run   # from this demo (or jolt run, jolt -M:run)
bb input-box             # from the repo root (or jolt -M:input-box)
```

## About

raylib [text] example - a text input box. Type printable characters
(GetCharPressed), backspace deletes, a blinking cursor blinks, ENTER clears.
Uses the get-char-pressed / get-key-pressed binds. See README.md.
