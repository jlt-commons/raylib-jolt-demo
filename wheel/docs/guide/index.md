# wheel

scroll a box with the mouse wheel

Category: core

Ported from raylib's `examples/core/core_input_mouse_wheel.c`.

![wheel](../demos/wheel.gif)

## Run it

```sh
cd wheel && bb run   # from this demo (or jolt run, jolt -M:run)
bb wheel             # from the repo root (or jolt -M:wheel)
```

## About

raylib [core] example - mouse wheel (`joltc -M:wheel`).

Ported from examples/core/core_input_mouse_wheel.c: scroll the mouse wheel to
move a box up and down. Exercises a float-returning binding (GetMouseWheelMove).
