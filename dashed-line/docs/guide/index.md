# dashed-line

a dashed line follows the mouse

Category: shapes

Ported from raylib's `examples/shapes/shapes_dashed_line.c`.

![dashed-line](../demos/dashed-line.gif)

## Run it

```sh
cd dashed-line && bb run   # from this demo (or jolt run, jolt -M:run)
bb dashed-line             # from the repo root (or jolt -M:dashed-line)
```

## About

raylib [shapes] example - dashed line (`joltc -M:dashed-line`).

A dashed line from the screen centre to the mouse, drawn as a series of short
segments with gaps (every other segment).
