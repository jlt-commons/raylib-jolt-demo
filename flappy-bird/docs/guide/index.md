# flappy-bird

flap through the pipe gaps (SPACE)

Category: games

![flappy-bird](../demos/flappy-bird.gif)

## Run it

```sh
cd flappy-bird && bb run   # from this demo (or jolt run, jolt -M:run)
bb flappy-bird             # from the repo root (or jolt -M:flappy-bird)
```

## About

raylib [games] example - flappy bird. SPACE to flap; fly through the pipe gaps.
Gravity + scrolling pipes + AABB/circle collision, all in Clojure.
